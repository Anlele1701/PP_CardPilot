# T-S03.1 — Login API — POST /api/auth/login

**Parent:** [T-S03 — Login Screen](./README.md)
**Module:** `BE`
**Status:** Backlog

## Mô tả

`POST /api/auth/login` — verify email/password (hoặc uỷ quyền Supabase Auth tuỳ T-BE-004), issue access token + refresh token.

## Acceptance Criteria (riêng phần BE)

- [ ] Email tồn tại + password đúng → `200` trả `{ accessToken, refreshToken, user: { id, email, full_name } }`
- [ ] Email không tồn tại HOẶC password sai → `401` với message chung chung, KHÔNG phân biệt 2 trường hợp (chống user enumeration)
- [ ] Password verify bằng hash so sánh (bcrypt/argon2), không so sánh plaintext
- [ ] Nếu JWT tự xây: refresh token được lưu vào `refresh_tokens` (T-BE-010) trước khi trả về
