# T-S03.1 — Supabase token verification + user bootstrap API

**Parent:** [T-S03 — Login Screen](./README.md)
**Module:** `BE`
**Status:** Backlog

## Mô tả

Mobile login đã được uỷ quyền cho Supabase Auth. Backend cần verify Supabase
Bearer token và cung cấp endpoint bootstrap để tạo/tải `public.users` theo
`auth.users.id`; backend không nhận password và không tự phát hành token pair.

## Acceptance Criteria (riêng phần BE)

- [ ] Email tồn tại + password đúng → `200` trả `{ accessToken, refreshToken, user: { id, email, full_name } }`
- [ ] Email không tồn tại HOẶC password sai → `401` với message chung chung, KHÔNG phân biệt 2 trường hợp (chống user enumeration)
- [ ] Password verify bằng hash so sánh (bcrypt/argon2), không so sánh plaintext
- [ ] Request thiếu/sai/hết hạn Supabase Bearer token bị từ chối nhất quán
- [ ] Bootstrap idempotent, không tạo trùng `public.users` cho cùng `auth.users.id`
