# T-S03.2 — Login screen UI/logic

**Parent:** [T-S03 — Login Screen](./README.md)
**Module:** `MOBILE`
**Status:** In Progress

## Mô tả

Implemented as `features/auth/presentation/views/sign_in_screen.dart` with
app-owned form widgets and shared `cardpilot_ui` button/social primitives.
Authentication currently calls Supabase Auth directly instead of `T-S03.1`.
The screen supports email/password, Google/Facebook, loading/error state,
navigation to Sign-up, and `Continue as guest` into shared initial setup.

Remaining: forgot-password, backend Bearer-token integration/profile bootstrap,
and SQLite persistence for guest mode.
