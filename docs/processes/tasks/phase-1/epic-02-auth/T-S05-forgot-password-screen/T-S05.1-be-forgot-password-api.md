# T-S05.1 — Forgot Password API — POST /api/auth/forgot-password

**Parent:** [T-S05 — Forgot Password Screen](./README.md)
**Module:** `BE`
**Status:** Backlog

## Mô tả

`POST /api/auth/forgot-password` — gửi email reset (cần chọn email provider — chưa xác nhận trong `PROC-CICD`, hiện không có secret nào cho email provider).

## Acceptance Criteria (riêng phần BE)

- [ ] Chọn xong email provider (SMTP/SendGrid/SES/...) — ghi lại lựa chọn + lý do
- [ ] Email tồn tại → gửi email chứa link/OTP reset (TTL cụ thể — đề xuất giống pattern OTP khác trong hệ thống nếu có), trả `200` chung chung
- [ ] Email không tồn tại → vẫn trả `200` với cùng message (không tiết lộ enumeration)
