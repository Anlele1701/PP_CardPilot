# T-S04.2 — Gán membership Bronze mặc định khi tạo user

**Parent:** [T-S04 — Register Screen](./README.md)
**Module:** `BE`
**Status:** Backlog

## Mô tả

Khi `T-S04.1` tạo `users` record thành công → tự động tạo `user_memberships` record với `membership_id` = Bronze, `status='active'`. **Cross-epic**: logic nghiệp vụ thuộc Epic 3 — Membership, nhưng trigger tại thời điểm Register nên đặt subtask ở đây để không tách rời khỏi luồng "đăng ký xong thì có tier gì".

## Acceptance Criteria (riêng phần BE)

- [ ] Ngay sau khi tạo user thành công, tồn tại đúng 1 `user_memberships` record cho user đó với tier Bronze, `status='active'`
- [ ] Nếu bước gán Bronze thất bại, toàn bộ transaction tạo user phải rollback (không tạo user "mồ côi" không có tier) — dùng DB transaction bao cả 2 bước
