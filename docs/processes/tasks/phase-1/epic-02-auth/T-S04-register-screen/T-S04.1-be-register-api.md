# T-S04.1 — Bootstrap backend user from Supabase identity

**Parent:** [T-S04 — Register Screen](./README.md)
**Module:** `BE`
**Status:** Backlog

## Mô tả

Supabase Auth sở hữu đăng ký email/password và OAuth. Sau khi mobile có
Supabase session, backend verify Bearer token rồi idempotently tạo/tải
`public.users` theo `auth.users.id`. Backend không lưu password hash.

## Acceptance Criteria (riêng phần BE)

- [ ] Email chưa tồn tại + password hợp lệ → tạo `users` record, trả `201` kèm access/refresh token
- [ ] Email đã tồn tại → `409 Conflict`, không tạo record trùng
- [ ] Password lưu dưới dạng hash (bcrypt/argon2), không lưu plaintext
- [ ] Response không trả lại password/password_hash dưới bất kỳ hình thức nào

## DB Migration

Có điều kiện — thêm cột `password_hash` vào `users` nếu không dùng Supabase Auth
