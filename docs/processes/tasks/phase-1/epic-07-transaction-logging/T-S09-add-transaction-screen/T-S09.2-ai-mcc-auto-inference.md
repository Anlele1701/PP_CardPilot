# T-S09.2 — MCC auto-inference khi tạo giao dịch

**Parent:** [T-S09 — Add Transaction Screen](./README.md)
**Module:** `AI`
**Status:** Backlog

## Mô tả

Trong lúc xử lý `T-S09.1`: lookup `merchant_mcc_candidates` theo `merchant_id` (đã normalize qua `T-AI-001`), ưu tiên candidate có confidence cao nhất + `status='verified'`, gán `mcc_code` cho giao dịch.

## Acceptance Criteria (riêng phần AI)

- [ ] Merchant đã có candidate `verified` → gán đúng MCC đó, không cần user chọn tay
- [ ] Merchant chưa có candidate nào (lần đầu gặp) → giao dịch vẫn tạo được, `mcc_code` để trống/null, không chặn luồng tạo giao dịch
- [ ] Merchant có nhiều candidate `pending` (chưa verified) → chọn candidate có tỷ lệ feedback đồng thuận cao nhất, không chọn ngẫu nhiên
