**Parent:** [T-S09 — Add Transaction Screen](./README.md)

**Status:** Backlog

## Mô tả

Ghi log giao dịch thủ công vào `transactions`: validate `user_card` thuộc về user hiện tại, `amount > 0`.

## Acceptance Criteria (riêng phần BE)

- [ ] `user_card_id` không thuộc về user hiện tại → `403`
- [ ] `amount <= 0` → `400`
- [ ] Tạo thành công → trả về `transaction` đã tạo kèm `mcc_code` (từ T-S09.2) và `estimated_cashback_amount` (từ T-S09.3) trong cùng response, để mobile không cần gọi thêm request
