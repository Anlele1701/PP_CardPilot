# T-S10.1 — GET /api/transactions (list, filter card/date)

**Parent:** [T-S10 — Transaction History Screen](./README.md)
**Module:** `BE`
**Status:** Backlog

## Mô tả

`GET /api/transactions` — list giao dịch của user hiện tại, hỗ trợ query param filter theo `user_card_id` và khoảng ngày, phân trang.

## Acceptance Criteria (riêng phần BE)

- [ ] Không truyền filter → trả toàn bộ giao dịch của user, sort mới nhất trước, có phân trang (`limit`/`offset` hoặc cursor)
- [ ] Truyền `user_card_id` → chỉ trả giao dịch của thẻ đó
- [ ] Truyền khoảng ngày → chỉ trả giao dịch trong khoảng đó
- [ ] Sử dụng index `idx_transactions_user_card_date` (đề xuất ở `ARCH-DB`) để query nhanh khi data lớn
