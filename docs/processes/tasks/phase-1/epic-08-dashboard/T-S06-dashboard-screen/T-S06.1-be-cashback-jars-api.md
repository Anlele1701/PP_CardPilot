## Acceptance Criteria (riêng phần BE)

- [ ] Trả về 1 item / thẻ user đang sở hữu: `{ user_card_id, used_amount, cap_amount, cycle_start, cycle_end }`
- [ ] Thẻ chưa có giao dịch nào trong chu kỳ → `used_amount = 0`, không lỗi
- [ ] Tính đúng chu kỳ hiện tại dựa theo `billing_cycle_day` riêng của từng thẻ (2 thẻ khác billing day → 2 khoảng chu kỳ khác nhau)
