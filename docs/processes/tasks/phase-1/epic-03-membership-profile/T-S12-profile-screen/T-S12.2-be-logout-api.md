# T-S12.2 — Custom backend logout endpoint

**Parent:** [T-S12 — Profile Screen](./README.md)
**Module:** `BE`
**Status:** Not Required

## Mô tả

Supabase Auth đang sở hữu session và refresh-token rotation; mobile logout bằng
`supabase.auth.signOut()`. Vì backend không phát hành session riêng nên hiện
không cần `POST /api/auth/logout`. Chỉ mở lại task nếu sau này backend quản lý
server-side session/revocation riêng.

## Acceptance Criteria (riêng phần BE)

- [ ] Gọi thành công → refresh token cũ không dùng lại được nữa (verify bằng cách thử gọi refresh sau khi logout, phải fail)
- [ ] Access token hiện tại (nếu còn hạn) tự hết tác dụng theo đúng TTL đã cấu hình (không cần blacklist access token riêng nếu TTL đủ ngắn — quyết định cụ thể theo T-BE-004)
