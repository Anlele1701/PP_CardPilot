# T-S12.1 — GET /api/memberships + /api/users/me

**Parent:** [T-S12 — Profile Screen](./README.md)
**Module:** `BE`
**Status:** Backlog

## Mô tả

`GET /api/users/me` trả thông tin user + membership tier hiện tại; `GET /api/memberships` trả danh sách toàn bộ tier + giới hạn (phục vụ hiển thị lộ trình lên hạng).

## Acceptance Criteria (riêng phần BE)

- [ ] `GET /api/users/me` trả `{ id, email, full_name, born_date, membership: { name, max_cards, ... } }`
- [ ] `GET /api/memberships` trả danh sách đầy đủ tier đã seed (từ T-DATA-001), sắp xếp theo thứ hạng tăng dần
- [ ] Không có token / token hết hạn → `401` (qua `T-BE-009` Auth Guard)
