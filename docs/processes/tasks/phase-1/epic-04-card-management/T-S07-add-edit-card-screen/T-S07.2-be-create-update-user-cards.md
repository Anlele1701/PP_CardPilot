# T-S07.2 — POST + PATCH /api/user-cards (create/update)

**Parent:** [T-S07 — Add/Edit Card Screen](./README.md)
**Module:** `BE`
**Status:** Backlog

## Mô tả

`POST /api/user-cards` (thêm thẻ) + `PATCH /api/user-cards/:id` (sửa nickname/billing_cycle_day/is_default). Validate `credit_card_id` tồn tại trong catalog trước khi cho thêm.

## Acceptance Criteria (riêng phần BE)

- [ ] `POST` với `credit_card_id` không tồn tại → `400`
- [ ] `POST`/`PATCH` với `billing_cycle_day` ngoài 1-31 → `400`
- [ ] Đặt `is_default=true` → toàn bộ `user_cards` khác của user tự động set `is_default=false` (transaction đảm bảo chỉ 1 default)
- [ ] `PATCH` thẻ không thuộc về user hiện tại (thử sửa `user_card_id` của người khác) → `403`/`404`, không lộ thông tin thẻ người khác
