# T-S07.3 — Enforce max_cards theo tier

**Parent:** [T-S07 — Add/Edit Card Screen](./README.md)
**Module:** `BE`
**Status:** Backlog

## Mô tả

Trong `POST /api/user-cards` (T-S07.2): trước khi tạo, đếm số `user_cards` hiện có của user, so với `memberships.max_cards` theo tier hiện tại (từ T-S12.1/`user_memberships`), chặn nếu vượt.

## Acceptance Criteria (riêng phần BE)

- [ ] User đã có đúng `max_cards` thẻ, thêm thẻ mới → `403`/`422` kèm message rõ ràng nêu giới hạn hiện tại và tier
- [ ] User chưa đạt giới hạn → thêm bình thường
- [ ] Đổi tier (nâng hạng — thuộc Phase 2) không nằm trong scope task này — chỉ enforce theo tier hiện tại
