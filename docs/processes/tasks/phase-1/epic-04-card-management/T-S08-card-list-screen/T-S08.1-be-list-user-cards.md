## Mô tả

`GET /api/user-cards` — danh sách thẻ user hiện tại, kèm thông tin bank/credit_card (join) để hiển thị tên ngân hàng/sản phẩm mà không cần gọi thêm request.

## Acceptance Criteria (riêng phần BE)

- [ ] Trả danh sách đầy đủ, mỗi item có `nickname`, `billing_cycle_day`, `is_default`, tên bank + tên sản phẩm thẻ
- [ ] User chưa có thẻ nào → trả mảng rỗng (không lỗi)
